# Ketten Stúdió

Reszponzív esküvőszervező landing page tiszta HTML és CSS használatával.

## Fájlok

- `index.html` — az oldal tartalma és szerkezete
- `styles.css` — a teljes vizuális rendszer és a reszponzív nézetek
- `assets/` — az oldalon használt képek

## Helyi megnyitás

Az `index.html` közvetlenül megnyitható böngészőben, vagy a projekt gyökérmappája kiszolgálható bármely statikus webszerverrel.

## Megjegyzés

Ez egy egyetemi mintaprojekt, nem a Ketten Stúdió hivatalos weboldala. A kapcsolatfelvételi űrlap demonstrációs célú, nem küld és nem tárol adatot.
